# ci-trust-paths.txt — HIMMEL-3895 (HIMMEL-3815 slice F, threat T2).
#
# One extended regex (grep -E) per line, matched against every path a PR
# changes — both the new filename and, for a rename, the previous one. A PR
# touching ANY match cannot merge through scripts/handover/merge-on-green.sh
# without a trust-reviewed console GO (console-kit/go.sh --trust-reviewed).
#
# merge-on-green reads THIS FILE FROM THE REPO'S DEFAULT BRANCH via the GitHub
# API (never the PR head, the worktree or a local ref), so a PR that edits it
# cannot shrink the list it is judged by. An unreadable, empty or invalid list
# refuses. Blank lines and # comments are ignored; anchor every pattern.
