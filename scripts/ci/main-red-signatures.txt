# One extended regex (grep -E -i) per line, matched against a failed CI job's
# log by scripts/ci/classify-ci-red.sh. A match means the red is GENERAL (an
# advisory, an outage, a runner problem), not the PR's: the leg escalates it as
# MAIN-RED instead of fixing it in its own PR. Keep each pattern specific: a
# false match tells a leg to stop fixing its own red.

# npm audit advisories (a new advisory lands on main with no code change).
[0-9]+ (low|moderate|high|critical) severity vulnerabilit
npm audit (found|report)
# Registry / network / DNS.
ETIMEDOUT|ECONNRESET|EAI_AGAIN|ENOTFOUND
Temporary failure in name resolution
Could not resolve host
getaddrinfo
# HTTP 5xx and rate limits.
HTTP/?[0-9.]* ?5[0-9][0-9]
HTTP (error )?5[0-9][0-9]
API rate limit exceeded|secondary rate limit|rate limit exceeded
# Runner infrastructure.
The runner has received a shutdown signal
lost communication with the server
The operation was canceled\.$
# A gitleaks ruleset/version change surfaces as new findings on old code.
gitleaks.*(ruleset|rule set|rules?|version).*(chang|updat|upgrad)
